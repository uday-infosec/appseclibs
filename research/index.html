RESEARCH / ENGINEERING

Research

My work explores how application security can evolve alongside increasingly automated software development.

I focus on turning security research into practical engineering systems, with particular attention to reliability, verification, and developer adoption.

Research Areas

AI-Native Application Security

Exploring agent-assisted vulnerability discovery, security reviews, remediation, and developer-facing security automation.

Current investigations

  • Multi-agent vulnerability discovery and orchestration
  • Context limitations and incomplete security analysis
  • Reliability of AI-generated security fixes
  • Developer-triggered and IDE-integrated security workflows

Verifiable Security Automation

Investigating how automated security systems can produce outcomes that are reproducible, reviewable, and supported by evidence.

Current investigations

  • Preserving findings across agent executions
  • Deterministic completeness and coverage checks
  • Verification of vulnerability remediation
  • Human oversight and accountable automation

Software Supply Chain Security

Research and engineering focused on securing dependencies, build systems, and software delivery pipelines.

Areas of focus

  • Dependency confusion and package ecosystem security
  • CI/CD pipeline security
  • Software provenance and SLSA
  • Dependency governance and automated enforcement

Vulnerability Research

Exploring practical approaches to identifying and understanding vulnerabilities in complex applications.

Areas of focus

  • Desktop application fuzzing
  • Memory corruption and vulnerability discovery
  • Threat modeling
  • API security testing
